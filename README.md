# Вендинг автомат

Малък уеб симулатор на вендинг автомат, разработен с PHP и JavaScript. Потребителят може да добавя монети, да купува напитки, да получава ресто и да рестартира автомата.

## Стартиране

Нужен е PHP 8.0 или по-нова версия. От главната папка на проекта изпълнете:

```bash
php -S localhost:8000
```

След това отворете [http://localhost:8000](http://localhost:8000) в браузър.

## Структура

- `index.php` — потребителски интерфейс
- `api.php` — JSON API и PHP сесия
- `assets/app.js` — клиентска логика
- `src/` — бизнес логика на автомата

Състоянието на автомата се пази в PHP сесията, без база данни.

## Сервизни настройки

С бутон „Вход в сервизни настройки“ могат да се добавят напитки и приемани
номинали. Достъпът се пази само за текущата PHP сесия; изходът от сервизния
режим не изтрива състоянието на автомата. То се изчиства при „Рестарт“.

По подразбиране демо паролата е `service123`. За реална среда задайте
environment variable `VENDING_SERVICE_PASSWORD_HASH` със стойност, генерирана
чрез `password_hash()`. В сесията не се пази паролата, а само флаг за успешен
сервизен вход.
